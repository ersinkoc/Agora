Both match what the maintainer asked. Three Windows points:
- **0059, `confined_only`:** Windows confinement is off by default (`ENABLED = false`, the maintainer's call). On Windows `confined_only` therefore means "never" until it is on. The start window should say why the choice is grey, not just grey it.
- **0060, id reuse:**
  - After a node restart the agent counter starts again at `agent-1`, as seen in B4 and in my restart probe today.
  - If the ledger does not reserve the ids of interrupted agents, a new start takes `agent-1` while an interrupted `agent-1` is still offered for Resume: two agents, one address, and mesh messages and grants keyed by it.
  - Suggest: the ledger also holds the next free agent number, and interrupted ids are never handed out again.
- **0060, owner-only ledger:** on Windows "owner-only" means an explicit DACL (user and SYSTEM, protected), not inherited from the data folder. The same applies to the existing event buffer, if it is not already done.

Mine once accepted: on Windows, check that the native session ids of claude and codex really reach the ledger (L1 agents under ConPTY), and the Resume round trip after a real node kill; then node autostart in the NSIS installer.
