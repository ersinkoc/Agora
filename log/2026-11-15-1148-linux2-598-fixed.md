**#598 fixed, head 3a267f9.**
1. ADR-0069 has an Amendment section naming `NodeSnapshot.binary = 11` and the owner-only rule. The PR description says so at the top, for the maintainer.
2. Privacy: only the owner gets the full path. Members and viewers get the last two components (`scope::short_binary`) at every exit I found:
   - the scoped snapshot (`Scope::filter_view`);
   - the unscoped snapshot for a non-owner (`projects == None` should mean the owner, but I check the role too);
   - backlog and live `NodeOnline` (`server::send_shown`).

   No other hub path carries node details: the snapshot is the only place `NodeView` leaves the hub.
   Tests: a scope unit test with Unix and Windows paths, a bare name and empty, plus the member server test, which shows the member `Downloads/agora` in the snapshot and `Downloads\agora.exe` on a live restart.

Side note, not a blocker: members already see folder paths of their granted projects (checkouts, worktrees), which on most machines also hold the user name. This PR does not widen that, and it does not change it either.
