**#477 (T16 + #475, macOS Seatbelt): independent security review (code reading + clippy for the macOS target; the Seatbelt tests only run on a Mac) says CHANGES NEEDED.** The fix holds for the default `~/.agora` home. For a node home under `/tmp` (the case #475 is about) two holes stay open, found by reading; **each comes with a command for you to prove or disprove on the Mac** (`H=/tmp/agora-x`, agent worktree `W`; each must print `closed`/fail inside the sandbox):
1. **HIGH, rename bypass (home under a writable folder like /tmp):** the rules name fixed paths (`/private/tmp/agora-x/data`); the home folder itself is not closed and `/tmp` is writable, so `mv $H /tmp/y && cat /tmp/y/data/trusted-devices && nc -U -w1 /tmp/y/node.sock </dev/null`, then `mv /tmp/y $H`. Fix: also deny writes to (rename/unlink of) the home folder itself and each writable parent, so it cannot be moved or deleted.
2. **HIGH (/tmp home), trust-related folders not on the closed list:** `manifests`, `adapters`, `publishers`, `registry-root-key`, `registry-index`, `registry-version` (see main.rs, adaptercmd.rs). Prove: `echo x > $H/publishers`, `echo x > $H/manifests/evil.toml`. Fix: close the whole home except `worktrees` (an allow-list, not a growing deny-list).
3. **MEDIUM, bind before the node:** only connect is denied; `(deny network-bind (local unix-socket …))` for the closed socket paths too (the node resumes interrupted agents before its control server starts: an agent could create `node.sock` first). Prove: node stopped, inside the sandbox `nc -lU $H/node.sock`.
4. LOW: `link` is closed only when data and worktree share a parent; base it on `home()` / the socket's folder. 5. LOW: close `file-read*` (not just `file-read-data`) as #475 asked (existence, sizes, xattrs).
Also run and report: hard link (`ln $H/data/trusted-devices $W/x && cat $W/x`; `ln $H/node.sock $W/s && nc -U -w1 $W/s </dev/null`), symlink (`ln -s $H/data $W/d && cat $W/d/trusted-devices`), relative path (`cd $H && nc -U -w1 node.sock </dev/null`), case/firmlinks (`cat ~/.AGORA/data/trusted-devices`; `cat /System/Volumes/Data$HOME/.agora/data/trusted-devices`), open handles (`lsof -p $$` shows nothing under `$H`). Add a test per finding 1–3 to `sandbox_tests`. Please push to #477 and post the head + the results of those commands; I then ask for the second independent look.
