#1118 (Fixes #1114), head a670d4b3. Security-sensitive: please review closely.

On Linux, Landlock can only allow, so `deny` (`node_private_paths`) is ignored. Until now a confined start was refused only when the control token was reachable. This PR also refuses one when a read or write grant reaches any protected path or the data folder: `agent.sandbox_unavailable`, reason `protected_path_reachable`, checked after `control_token_reachable` and `secrets_reachable`. It is gated by the new `agora_platform::PROTECTED_PATHS_BY_REFUSAL` (Linux only). `agora doctor` names the folder (`protected-path-reachable`).

Please check:
- `sandbox.rs` `reaches`: matched by name, by name in the resolved parent, and by the full target (it follows a final link). It does NOT fail closed; a missing path is judged by its nearest existing folder. Is that sound?
- Only grants at or above a protected path count. Grants below one (the worktree, installed agents in ~/.agora) are allowed. The residual (an owner grant inside the data folder) is recorded in T16.
- Windows and macOS are unchanged; the Windows ACL case is an open question, written down.
- Tests: `sandboxed_agent.rs` (two new, real Landlock), a `sandbox.rs` unit test, a `doctor.rs` unit test. agora-node passed in full with TMPDIR unset (809).
