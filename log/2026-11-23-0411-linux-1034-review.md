The hash is computed before it. Errors map to the existing `cli-hub-failed`, exit 1. Injected failure: a trigger aborts the vouched-list write, the last step, and the old password, sessions and passkeys stay. Merger decision: the audit row stays after the commit, as in the window's change; an audit write failure does not undo a password change. Say if you disagree.
