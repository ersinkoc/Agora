**M2.6: one design point needs your answer before I write link code. Everything else I'm starting now, platform-only.**

**The question: how a terminal crosses the link on Windows.** Windows has no `SCM_RIGHTS`. The holder must `DuplicateHandle` the two pipe ends (agent input write end, output read end) into the node's process, through the same handle that passed the start-time check (ADR-0079 D5), and the node must learn the two handle values. `read_frame` reads a byte stream, so there is no side channel.
- **(A) Proposed: an in-band terminal reference in the frame.** New tags `StartedRef`(71) and `TerminalRef`(72): the same fields as `Started`/`Terminal`, plus `terminal: bytes`, an opaque blob the platform makes and reads:
  - the holder makes it with `TerminalHandle::export_to(&ProcessWatch) -> Vec<u8>` (duplicates into that process);
  - the node reads it with `TerminalHandle::import(&[u8]) -> io::Result<TerminalHandle>`;
  - a platform const (like `HOLDER_BUILT`) picks the tag, so neither crate gets an OS branch;
  - the decoder knows both tags on every OS. Unix keeps 67/69 with `SCM_RIGHTS`, unchanged.
  - **No version bump**, I think: a Unix holder never sends 71/72, and no older Windows holder exists. But if you want new tags to bump `LINK_VERSION`, say so.
  - Spec and golden fixtures are added for 71/72.
- (B) The alternative is a hidden platform envelope inside `send/recv_with_terminal` on Windows: a second framing under the link's framing, which is invisible in the spec and harder to test. I'd rather not.
- **Also on Windows:** resize can't use the master (the pseudoconsole stays in the holder). So `HeldControl` gets `resize(cols, rows)` with a default `Unsupported`, the node's control sends the existing `Resize`(4), and Unix doesn't change.

**What `HeldSignal` will mean on Windows (holder side, in `conpty.rs`):**
- Interrupt: `0x03` into the pseudoconsole's input, which raises Ctrl-C in its console processes.
- Hangup: close the pseudoconsole (CTRL_CLOSE_EVENT).
- Terminate: hang up, then kill after the grace time.
- Kill: `TerminateJobObject` on the agent's job.
