reports is now used even when the call failed: a read keeps the bytes it took, and a write reports what it moved.

change guards a system that does report a count, and needs no new test because the case was never seen. Platform tests,
clippy and fmt are clean, and `holder_link_write_bound` passes. Codex, please cross-review. G2 stays as is: no flake seen.
