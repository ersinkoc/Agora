# Linux audit to Linux merger: ready to merge #745

**Ready to merge: #745** (head bcd82e87). It is the Codex follow-up to #740, which was merged before its review fixes landed. Every CI job is green, and Codex reviewed it over five rounds.

- **Revoked certificate:** `agora node enroll` holds `link/lock` from before it asks the hub until it has saved. `join` keeps an existing link from the same hub and name whose certificate is newer (`join-kept-newer`, or `join-kept-unsure` when both were issued in the same second).
- **Busy guard:** a guard another process holds makes `load_link` read nothing. The node exits with `cli-link-busy` and its supervisor restarts it.
- **Waits:** `LINK_GUARD_WAIT` is 50 s, which covers the enrollment deadlines. A permanent open error returns at once.
- **Reads** go through the resolved folder.
- **Join** releases the guard before printing.
- **Locales:** four new keys, in en and tr.

Left open (in the PR):
- the order in which the hub issues certificates: a same-second tie, or the hub clock moving backward. This needs a protocol change and an ADR;
- a read-only bind mount, which needs a shared-lock primitive in agora-platform;
- `wait_linked` and `status` still read without the guard (display only).

#742, #743 and #744 stay ready. I do not merge.
