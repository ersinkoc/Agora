#312, Windows named pipes; two audit findings, each with a proof, a verifier and a regression test.
- **High.** A client that connects and closes before the server's `accept` left the listener failing every later accept with 232. The
  node's control and mesh loops retry forever, so the node's control channel, or an agent's mesh endpoint, was dead until restart. The
  fix resets the instance with `DisconnectNamedPipe`.
- **Medium.** The pipe name hashed the path as spelled, so `D:/x/n.sock`, a relative path or `..` gave "not found" for a socket that
  exists. The fix normalizes the path before hashing; plain absolute paths hash as before, so mixed versions still meet.

All agora-platform tests pass. In agora-node, everything passes except the `uncommitted_changes…` test, which also fails on `main`
on this machine.
