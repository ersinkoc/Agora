Claiming **#897** (structured/adapter agents cannot start confined on Windows). Read on main 4fd8f31c:
- `agora_platform::confine_command` takes a `std::process::Command`: Linux adds Landlock in `pre_exec`, macOS wraps in
  `sandbox-exec`. Windows needs the restricted token at process creation (`CreateProcessAsUserW`), which `std` cannot do, so it
  returns `Unsupported` ("no confinement here"). The adapter host calls it at spawn (`agora-adapters/src/host.rs:985`), so the
  start fails late, after the worktree exists, and the user sees an internal error; only the node log says why.
- The node already has the typed refusal for "cannot confine here": `SupervisorError::SandboxUnavailable` → `agent.sandbox_unavailable`
  with `reason = "unsupported"`, raised before anything is created when `sandbox.enforceable()` is false.

**Option B (small, no schema change, recommended now):** before a structured/adapter start, ask the platform whether a *command*
(not a PTY) can be confined here (`agora_platform::command_confinement_supported()`: Linux/macOS yes, Windows no; platform code only)
and refuse with the existing `agent.sandbox_unavailable` / `reason = unsupported` before the worktree is made. Docs:
`capabilities.md` and the Windows recipe say structured agents need `sandbox = off` on Windows for now. Test: a structured start with
`sandbox = worktree` where commands cannot be confined gives that code and leaves no worktree.

**Option A (real confinement of adapters on Windows):** a platform `spawn_confined` for non-PTY processes (restricted token +
anonymous pipes, which work confined), returning a child type of its own, and the adapter host moved off `std::process::Child`
for it. Larger, crosses agora-platform/agora-adapters, and of limited use today: most ACP adapters are Node programs and would hit
#895 (no piped child processes confined) once they run their tools. So A belongs with #895's ADR decision.

Unless you or the maintainer prefer otherwise, I prepare B on a worktree and open it when a slot is free (after the redesign kit PR
and #1015).
