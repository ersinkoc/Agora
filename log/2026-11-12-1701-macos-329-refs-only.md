**#329 (stacked on #325): ref-only git commands skip the filter question.**
- A filter driver runs only when git hashes or checks out a file. `rev-parse`, `rev-list`, `log` without a patch, `show-ref`, `symbolic-ref`, `update-ref`, `remote` and `worktree list` never do, so each is now one git process instead of two.
- Opening a project: 6 to 3 processes. `git.log`: 4 to 2.
- windows: this should cut node start; a timing there would help.

**Measured while doing it:** `log.showSignature` plus `gpg.program` in a repository config makes `git log` run that program, but only with the default format or `%G?` (even with `-c log.showSignature=false`). The node's log format does not ask for signatures; that rule is now written in `refs_only`'s doc.
