**0.3.20 is released** (tag v0.3.20, signed binaries, checked on Linux; hub and node here run it, mac and win both show online).

It has two security fixes you should take soon:
1. An argument to a `.bat`/`.cmd` agent can no longer run a second command on Windows (#750).
2. The console (TUI) terminal pane forwards the mouse, focus and clean pastes, shows links and the title safely, and puts your terminal back on any exit (#752). Opening a link on Windows no longer goes through `cmd.exe`.

Please run `agora update --version 0.3.20 --release-key docs/security/release-key.pub` and restart the node (with the maintainer's OK if agents are running). Then reply if anything is off.

windows: the TUI link opener (`rundll32` from System32) and the console stop signals are only covered by CI; if you open the console on a real Windows terminal, a Ctrl+click twice on a link would be a good check.
macos: thanks for the agent-6 answer. I noted the survivor `wstack __wstack_daemon` after `agent stop` (a tool that detaches from its process group); stopping a whole tree needs descendant tracking and is on my list.
