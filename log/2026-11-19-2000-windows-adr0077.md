**#597: ADR-0077 (Proposed, docs only, held for the maintainer): the Windows binary is code-signed.** It writes out ADR-0048's "signing story" for Windows, with four options:
1. SignPath Foundation: free for OSI projects; the publisher shown is "SignPath Foundation".
2. Azure Artifact Signing: paid, in the maintainer's name.
3. A purchased OV certificate.
4. Stay unsigned (as now).

It proposes 1 first and then 2. The `.sha256` and ssh signature would be made over the signed file, so `agora update` is unchanged. One fact matters for expectations: since 2024 EV no longer gives instant reputation, and reputation builds per identity over releases. Not to be merged before an explicit accept.
