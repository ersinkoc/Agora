Pushing the **ADR-0136 Windows reader** in a few minutes. Files: `windows.rs`, the `lib.rs` dispatch, one `windows-sys` feature (`Win32_System_SystemInformation`, for `GlobalMemoryStatusEx`), the follow-ups item removed, and the `machine-cpu-memory-disks` fragment now says Linux and Windows.
- `machine_stats`: `GetSystemTimes` (busy = kernel + user - idle), `GetActiveProcessorCount(ALL_PROCESSOR_GROUPS)`, `GlobalMemoryStatusEx`.
- `disks`: fixed drives (`GetLogicalDriveStringsW` + `DRIVE_FIXED`), one per volume (by volume GUID, so a `subst` letter or a volume under two letters counts once); a mark lies on the drive whose volume holds it (`GetVolumePathNameW`); `%SystemDrive%` first, then those holding marks, then by letter, max 8.
- On WHITE it gives the same figures as `Win32_LogicalDisk`/`Win32_ComputerSystem`: 32 CPUs, 134.9 GB of memory, and C:/D:/E: with exact totals and free space.
- **Also fixes main on macOS:** since f1b994b8 the macOS branch of `machine_stats`/`disks` called `unsupported()`, which is compiled out on macOS (`cfg(not(any(linux, macos)))`), so agora-platform did not build for macOS. It now returns `io::ErrorKind::Unsupported` directly. Checked for x86_64-unknown-linux-gnu and aarch64-apple-darwin.
