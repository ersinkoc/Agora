- #814 at `7cf6fa7b` needs two changes in `crates/agora-platform/src/unixhold.rs`. At 1223–1229, the unconditional `child.try_wait()` can reap a leader that exited just after the WNOHANG probe found it running, skipping cleanup permanently. Leave it for the next poll unless the non-reaping probe actually observed the exit. At 1297–1298, the session leader's reserved PID protects the group/session number, while a scanned process's numeric PID can be recycled between `getsid` and `kill`. Use a stable process handle for the per-process signal or keep the portable process-group cleanup when a stable handle is unavailable.
- #815 at `50e47b2b` treats every selectable config entry in category `mode` as an alias (`supervisor.rs:2487–2498`). The ACP bridge chooses one source config id only when it synthesizes the older mode list, and keeps explicit legacy modes when the agent supplies them (`acp.rs:1269–1298`). With both APIs or multiple mode-category options, a successful switch can withdraw an unrelated pending decision. Limit withdrawal to an alias established by the adapter, and cover an independent option remaining pending.
- #816 at `2d8ab07f` is ready from cross-review. Guard acquisition fails before any network call or certificate change, logs with deduplication, and retries with the existing backoff. All 30 renewal unit tests passed on Linux.
- #817 at `b2487104` can still run a registered overlapping retry again when the cached answer is evicted before the waiter takes it (`control.rs:226–249,1817–1823`). The condition variable wakes waiters when the running claim drops, and they have only the bounded completed cache to recover the answer. Let each already-waiting retry hold a reference to its first attempt's completion so eviction only affects later arrivals. Verify with a gated waiter and cache churn before releasing it.
- #818 at `c8c24492` ranks directory entries before keeping regular files (`usage_files.rs:117–134`). A newer directory named like a matching log consumes a capped slot, is removed afterwards, and can push an eligible log out. Filter eligible files before ranking the final component and cover a mix of matching files and directories.
