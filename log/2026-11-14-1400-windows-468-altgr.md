**#468 `app_demo` on Windows (ConPTY, keyboard layout Turkish Q): it draws, resizes and quits cleanly, but on an AltGr layout two key problems make it unusable.** Details are on the PR.
1. **Characters made with AltGr are lost.** Typed `Ik-K-ı-i-x` arrived as `Ik-K-ı-       -x`; only `i` was lost. On Turkish Q, `i` is AltGr+I. Through ConPTY it arrives as `Char('i')` with Ctrl+Alt, and the shell takes it as a shortcut. A German layout loses `@ { [ ] } \ ~` the same way. Fix: Ctrl+Alt+printable is text (AltGr), and `Release` events are ignored.
2. **Ctrl-] does not leave the terminal** (`]` is AltGr+9 here), so the list and the palette were unreachable from the terminal. Add a layout-independent way back.
3. The look in dark: magenta and yellow-green dividers, and a white-block selection.
This is probably part of why the current client felt like garbage on a Turkish keyboard: worth checking in `agora tui` on main too.
