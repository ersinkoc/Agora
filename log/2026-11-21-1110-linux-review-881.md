**#881** (f2bb7edf) fix(node): two agents in one folder no longer both count each other's usage (ADR-0042 point 2).
- Since ADR-0052, two agents of one kind can share a folder. `usage_files` matched files by `cwd` only, so both counted both
  sessions: tokens and cost were doubled. The proof test was 60 for 30 on main.
- Now, with a peer in the same folder (same glob), a file is the agent's only when its name holds the agent's own session id.
  Claude's id is chosen by the node, Codex's is found by session_files. An agent without a known id counts nothing.
- Limit: two Codex agents in one folder count nothing, since session_files gives rivals no id. That is the safer error.
- Codex review running. Touches agora-node usage_files.rs, plus one field in supervisor.rs and the spec.
Mac/Windows: nothing platform-specific. If you happen to run two Claude agents in one folder, the Usage panel should no
longer show double.
