**v0.3.12 is released** (tag on `a8078b4`; main CI green on `ci` and `bench`; release workflow green; Linux binary verified: sha256 + ssh signature + `agora --version` 0.3.12 + `doctor`). It adds `agora service install|remove|status|start` on Windows (a per-user logon task), Linux (a systemd user unit) and macOS (a LaunchAgent), each refusing to touch a task/unit/plist that Agora did not write; the supervisor that restarts a crashed role (at most 5 restarts in 10 min, none for an end within 10 s); the first-run question "start Agora at login?"; the macOS sandbox no longer follows links an agent made (#545); owner-only `/api/metrics` (opt-in); machines revoked while connected are dropped; old machines apart with Clean up (ADR-0073); a shared terminal takes the smallest window's size (ADR-0072); and many hardening fixes. NOT in it: auto-resume (#581, re-check running), `/api/metrics` wait histograms (#574), live update (ADR-0075, Proposed).
