# Real-machine run on Linux, 2026-11-21 (roadmap M1.1)

The first run of [the real-machine checklist](real-machine-checklist.md). It was run by an agent session (Claude Code) on blackview,
the machine that also runs the maintainer's own Agora hub, node and agents, so every step used a disposable `AGORA_HOME`, a run
folder and its own ports, and stopped only the processes it started.

- **Agora:** 0.3.33 (the installed release, `~/.local/bin/agora`); `agora-fake-agent` built from the `v0.3.33` tag in `$RM/src`.
- **Machine:** blackview, Ubuntu 26.04.1 LTS (kernel 7.0.0-42-generic), AMD Ryzen 5 7430U (6 cores, 12 threads).
- **Browser:** headless Chromium 156.0.8078.4 (Playwright's build, driven by playwright-core), viewport 1440×900, scale 1; other
  profiles for browser B, the viewer and the remote sign-in. **Terminal client:** `agora tui` under a pty driven from Python (pexpect
  and a pyte screen), 80×24, 110×30 and 140×40.
- **Run folder:** `$RM` = `~/rm-2026-11-21` (deleted after the run); run hub on port 7443 (the machine's own is 7444),
  a second "fresh" home on 7445 for RM-06, a metrics hub on 17450; S3's second machine `rm-two` (home `$RM/two`, project `$RM/proj2`,
  a clone of `$RM/proj`); `rm-three` and `rm-four` (RM-07) in their own homes.
- **Run before the checklist's safety fixes (#894's last commits) reached this session:** S1 was answered `y` to "Let other machines
  of yours connect?" (as the draft said, for RM-07), so the run hub listened on 0.0.0.0:7443 during the run; S1 used `agora --ui none`
  and answered "Bring agents back by themselves after a restart?" with `n` and the login question with `n` (both explicit; the
  machine's own `agora-hub`/`agora-node` units were checked unchanged); RM-06 used plain `agora`, which opened the window. No
  confined agent was started (#900), no global git configuration was read or changed, no file under `~/.ssh` was read.
- **Result:** 26 pass, 11 fail, 23 skip. Issues: #901, #902, #903, #904, #905, #906, #907 (RM-34 and RM-47), #908, #909, #910.
- **Checklist steps corrected in this pull request:** S2 (rule `id`/`priority`, the `idle` regex, the `blocked` region, the
  `rm-helper` kind, which manifests the run verified), RM-07, RM-11, RM-13, RM-14, RM-20, RM-21, RM-24, RM-26, RM-36, RM-44, RM-49
  (the probe and where the board is), RM-55, RM-59.
