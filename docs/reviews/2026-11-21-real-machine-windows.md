# Real-machine run on Windows, 2026-11-21 (roadmap M1.1)

The Windows run of [the real-machine checklist](real-machine-checklist.md), after [the Linux run](2026-11-21-real-machine-linux.md).
It was run by an agent session (Claude Code) on WHITE, the maintainer's own Windows machine, which also runs its own Agora node
(`win`) under its own scheduled task. Every step used a disposable `AGORA_HOME` inside the run folder and its own ports, and stopped
only processes it had started (checked by command line before each stop); the machine's own task, node, agents and
`%USERPROFILE%\.agora` were not touched.

- **Agora:** 0.3.33 (the published `agora-x86_64-pc-windows-msvc.exe`, sha256 `4274da7a…`, copied to `$RM\bin\agora.exe`);
  `agora-fake-agent` built from the `v0.3.33` tag (release profile).
- **Machine:** WHITE, Windows 11 Pro 10.0.26300, Git 2.56.1.windows.1, Windows PowerShell 5.1 for the Shell kind.
- **Browser:** Chrome driven by Playwright, CSS 1536×864 at 125 % (deviceScaleFactor 1.25); a second profile at 1280×720 and 150 %
  for RM-58; more profiles for browser B and C (RM-25, RM-36). **Terminal client and the front door:** `agora` and `agora tui` under a
  ConPTY pseudoconsole driven by a small test program (the front door refuses a non-terminal stdin, as it should), 80×24, 120×35
  and 140×40.
- **Run folder:** `$RM` = `%TEMP%\agora-rm-20261121T230121` (deleted after the run); run hub 127.0.0.1:7443 (S1 answered `n` to other
  machines); RM-06's fresh home on 7444; a metrics hub on 17450; S3's `rm-two` (home `$RM\two`, project `$RM\proj2`, a clone of
  `$RM\proj`); `rm-join` and `rm-join3` (RM-07) in their own homes. No confined agent was started ([#900](https://github.com/ersinkoc/Agora/issues/900)); no global Git
  configuration was read or changed.
- **Result:** 29 pass, 6 fail, 25 skip. New issues: [#939](https://github.com/ersinkoc/Agora/issues/939), [#940](https://github.com/ersinkoc/Agora/issues/940), [#941](https://github.com/ersinkoc/Agora/issues/941), [#942](https://github.com/ersinkoc/Agora/issues/942), [#943](https://github.com/ersinkoc/Agora/issues/943), [#944](https://github.com/ersinkoc/Agora/issues/944), [#945](https://github.com/ersinkoc/Agora/issues/945), [#946](https://github.com/ersinkoc/Agora/issues/946).   again here: [#902](https://github.com/ersinkoc/Agora/issues/902), [#903](https://github.com/ersinkoc/Agora/issues/903), [#905](https://github.com/ersinkoc/Agora/issues/905), [#908](https://github.com/ersinkoc/Agora/issues/908), [#910](https://github.com/ersinkoc/Agora/issues/910) (commented).
