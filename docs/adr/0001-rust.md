# 0001. Rust for node, hub, and TUI
Status: Accepted
Date: 2026-11-06

## Context
The node runs on every machine, including small VPSes and Windows, supervising PTYs with high-frequency I/O.
It must ship as one dependency-free binary per platform. The hub and TUI share the domain model and protocol.

## Decision
Write node, hub, TUI, and CLI in Rust as one Cargo workspace producing a single binary. The web client is
TypeScript and is embedded into the hub binary as static assets.

## Consequences
- One toolchain for all backend code; shared `agora-core` and `agora-protocol` crates.
- Cross-compilation for Windows and macOS must be set up early in CI.
- Dependency count must be actively controlled (see AGENTS.md).
