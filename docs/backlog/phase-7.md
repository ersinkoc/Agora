| P7-01 Windows node W1: named-pipe control channel | done (W1) | `crates/agora-platform/src/windows.rs`: `local_listen`/`local_connect`/`LocalStream` over a named pipe `\\.\pipe\agora-<file name>-<hash of the path>`, owner-only security descriptor (`D:P(A;;GA;;;OW)(A;;GA;;;SY)`), remote clients rejected, first instance exclusive (a second listener gets `AddrInUse`), overlapped I/O so a waiting read never blocks a write from another thread, read timeouts and `shutdown` by cancelling the pending read. `LOCAL_SOCKETS_SUPPORTED` is true on Windows. | P7-02 W2: ConPTY terminals and job objects | done (W2) | `crates/agora-platform/src/conpty.rs`: `spawn` starts the child attached to a pseudo-console (two anonymous pipes, `CreatePseudoConsole`, the pseudo-console process attribute), puts it in a job object that kills the tree when closed (and carries the memory and CPU limits), reads output on a thread into the same bounded channel, closes the console when the child ends so the output channel ends, resizes with `ResizePseudoConsole`. `foreground_pid` is the child itself (no foreground group on Windows). The child is started with `STARTF_USESTDHANDLES` and no handles: without it a parent whose own streams are redirected (a test harness, a service) makes the child write there instead of to the console (found on CI: `cmd /c echo` ended with its exit code but printed nothing).
